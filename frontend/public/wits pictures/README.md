# Album photographs

These eight photographs were supplied by the project owner for Wits Quest album covers. Original filenames are preserved. Photographer and licence details were not supplied.

`components/collection/CampusArtwork.tsx` maps explicit quest location keywords to the Great Hall, TW Khambule building, CLM building, fountain, gardens, or bus photographs. Other titles receive a stable campus scene; these are decorative covers, not verified photographs of those quests' locations. Paths are URL-encoded for spaces and Unicode filenames.

Individual cards use SVG emblems in `CardEmblem.tsx`, selected by card title, category, then quest title, with a compass fallback. Their enamel and metallic finishes follow the card's existing rarity. The old illustration atlas is no longer used by album covers or cards.
