# Sprint 1 Plan

**Duration:** 05 August 2026 – 25 August 2026 (3 weeks)

## Sprint Goal

Deliver the core authentication system (sign up, sign in, sign out, password reset, third-party login) along with the basic gameplay loop described in the project brief: campus map and events, location-based trivia challenges, card rewards, battles, and the content authoring console.

> **Note on scope:** Sprint 1 was originally planned around authentication only (see Meeting 1, 11 August). Following a client meeting on 21 August, the scope expanded to include the full set of basic features required for the first sprint marking on 25 August: map, events, cards, and battles. The backlog below reflects the final, expanded scope that was actually delivered.

## Team & Ownership

| Member | Focus area |
|---|---|
| Anovuyo | Authentication (sign up, third-party sign-in coordination), location verification, challenge submission and results |
| Busisiwe (nessaforealz) | Third-party sign-in, password reset, event proximity display, card rewards and collection, authoring console (events, questions, cards) |
| Lerato | Log out, account deletion, campus map display, battles system |


**Total points committed and completed:** 144

## Outcome

All 19 user stories planned for Sprint 1 were completed by the 25 August marking date, including the full basic feature set required by the client: authentication, map and events, trivia challenges, card rewards, battles, and the authoring console.
